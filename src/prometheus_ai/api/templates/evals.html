What these numbers do and do not prove

  • T1 is a harness test. It uses deterministic fixtures, so 100% action correctness means the plumbing and safety gate work — not that a model is accurate.
  • No live model run is published yet. Root-cause accuracy and variance require T2 with a real model; the README says so explicitly.
  • Faults are injected in a three-service demo cluster. This is not production incident handling.
  • With 15–40 scenarios the confidence intervals are wide; report them rather than a single point estimate.
